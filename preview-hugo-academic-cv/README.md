# Prévia — Tema Hugo Academic CV

Esta pasta é uma **prévia isolada**, gerada a partir do template
[HugoBlox / hugo-theme-academic-cv](https://github.com/HugoBlox/hugo-theme-academic-cv),
para avaliação visual do layout.

**Importante:**
- O conteúdo aqui é o conteúdo de **exemplo** que já vem com o template (nomes, bio,
  publicações e experiência fictícios) — nada do currículo real de Gustavo Paccelli
  foi migrado.
- É um build estático pré-gerado (HTML/CSS/JS), não afeta nem depende do site
  principal em nenhum arquivo (`index.html`, `css/`, `js/` etc. na raiz do repo).
- Serve apenas para visualização. Se o layout agradar, o próximo passo seria migrar
  o conteúdo real do portfólio para o formato de conteúdo do Hugo (Markdown +
  front matter) e decidir o pipeline de build/deploy definitivo.

Gerado com Hugo Extended v0.162.0 + Tailwind CSS v4.
